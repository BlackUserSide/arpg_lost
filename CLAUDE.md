ARPG для CrazyGames — проектный бриф

Браузерный ARPG в духе Path of Exile, но проще: короткие забеги, лут с аффиксами, билды через скиллы, модификаторы и дерево пассивок. Цель — публикация на CrazyGames (HTML5).

Платформа: ограничения CrazyGames
Публикация: ZIP-сборка загружается вручную через Developer Portal. Деплоя из git нет, обновлять можно в любой момент.
Два этапа: Basic Launch (SDK не обязателен, монетизации нет) → Full Launch (SDK обязателен, есть доход). В Full Launch приглашают по метрикам удержания.
Размер сборки: ≤ 50 МБ без SDK, ≤ 250 МБ с SDK. Ориентируемся на минимальный вес.
Реклама только через CrazyGames SDK (midgame, rewarded, баннеры). Никакой сторонней рекламы.
Никакого собственного логина. Прогресс привязан к аккаунту CrazyGames, автологин, их ник и аватар.
Обязательные события SDK: gameplayStart / gameplayStop, loadingStart / loadingStop.
Должно работать на десктопе и мобильных, во всех основных браузерах. Контент PEGI 12.
Монетизация: доля от рекламы (ориентир 60%, официально не опубликовано), IAP через Xsolla только для приглашённых игр.
Стек
TypeScript (strict), Vite.
Рендер: Phaser 4, 2D, вид сверху. TypeScript 6.0 (typescript-eslint пока не поддерживает 7.x).
Сохранения: на этапе MVP — localStorage за адаптером; после интеграции SDK — облачное хранилище CrazyGames через тот же адаптер.
Своего бэкенда в MVP нет. Код пишется так, чтобы core/ можно было позже запустить на сервере (мультиплеер, лидерборды, торговля).
Тесты: Vitest для core/.
Архитектура

Главное правило: игровая логика отделена от рендера.

src/
core/            # чистая логика, без Phaser и DOM
stats/         # статы, модификаторы, расчёт урона
combat/        # хит, крит, сопротивления, статусы
skills/        # исполнение скиллов по данным
items/         # генерация предметов, аффиксы, крафт
passives/      # дерево пассивок
progression/   # опыт, уровни, разблокировки
rng.ts         # детерминированный seeded RNG
data/            # конфиги в JSON/TS: классы, скиллы, аффиксы, мобы, карты
render/          # Phaser-сцены, спрайты, эффекты, UI
platform/        # обёртка над CrazyGames SDK + заглушка для локального запуска
save/            # адаптер сохранений (local / CrazyGames cloud)
core/ не импортирует ничего из render/ и platform/.
Всё, что можно описать данными, описывается данными: новые классы, скиллы, аффиксы и мобы добавляются конфигом, а не кодом.
Весь рандом через seeded RNG (воспроизводимость, тесты, будущая серверная валидация).
platform/ — единственное место, где вызывается SDK. Локально работает заглушка.
Система статов
Модификаторы трёх видов: flat (+10 к урону), increased (суммируются: +20% и +30% = +50%), more (перемножаются).
Итог: (base + flat) * (1 + Σincreased) * Π(1 + more).
Теги урона: physical, fire, cold, lightning; melee, projectile, spell, area. Модификаторы цепляются к тегам («+15% урона снарядами»).
Классы и скиллы (MVP)

У каждого класса 3 активных скилла. Скилл описывается конфигом: теги, базовый урон, стоимость маны, кулдаун, форма (дуга, снаряд, область, движение), эффекты.

Класс	Скилл 1	Скилл 2	Скилл 3
Воин (melee)	Рассекающий удар по дуге	Рывок с оглушением	Боевой клич: бафф урона
Рейнджер (projectile)	Веер стрел	Взрывная ловушка	Перекат с ускорением
Маг (spell)	Огненный шар, взрыв по области	Ледяная нова, замедление	Телепорт

Модификаторы скиллов (упрощённые камни поддержки): у скилла 2 слота. Примеры: доп. снаряды, увеличенная область, цепная молния, поджог при попадании, ускорение каста. Модификаторы выпадают как предметы.

Предметы
Слоты: оружие, шлем, броня, перчатки, ботинки, 2 кольца, амулет.
Редкость: обычный (0 аффиксов), магический (1–2), редкий (3–6).
Аффиксы: префиксы и суффиксы, у каждого тиры по уровню предмета, веса выпадения, теги допустимых слотов.
Генерация полностью из data/affixes.
Крафт (валюта)
Перекат аффиксов редкого предмета.
Добавление аффикса при наличии свободного слота.
Повышение редкости (обычный → магический → редкий).
Дерево пассивок
40–60 узлов, общая сетка для всех классов, у каждого класса своя стартовая точка.
Малые узлы (+статы) и несколько ключевых (меняют механику).
Очко пассивок за уровень, сброс за валюту.
Игровой цикл
Хаб: выбор персонажа, инвентарь, крафт, дерево пассивок.
Карта: забег на 3–5 минут, волны мобов, босс в конце.
Лут и опыт, возврат в хаб.
Карты имеют уровень; более высокие дают лучший лут.

Сессия должна укладываться в 3–5 минут — это формат браузерного портала.

Управление
Десктоп: WASD — движение, мышь — прицел, ЛКМ/ПКМ/Q/E — скиллы.
Мобильные: виртуальный стик и кнопки скиллов, автоприцел по ближайшему врагу.
Этапы

M1 — прототип ядра

Арена, персонаж одного класса, 1 скилл, мобы, хит/смерть.
core/stats и core/combat с тестами.

M2 — классы и лут

Выбор из 3 классов, все 9 скиллов из конфигов.
Выпадение предметов с аффиксами, инвентарь, экипировка влияет на статы.

M3 — прогрессия

Опыт и уровни, дерево пассивок, модификаторы скиллов.
Хаб и карты с боссом, сохранения через адаптер.

M4 — подготовка к Basic Launch

Мобильное управление, оптимизация веса, экран загрузки.
Сборка ZIP, проверка в Preview-инструменте портала.

M5 — Full Launch (после приглашения)

Интеграция CrazyGames SDK: события, реклама (rewarded: воскрешение, двойной лут), облачные сохранения, аккаунт.

Потом (с бэкендом)

Лидерборды с защитой, кооператив, торговля.
Сборка и деплой
npm run dev — локальная разработка.
npm run build — сборка в dist/.
npm test — тесты ядра.
GitHub Actions: на тег v* собирает проект, архивирует dist/ в ZIP и прикрепляет к релизу. На push в main — деплой на GitHub Pages для тестов с телефона.
Загрузка ZIP в CrazyGames Developer Portal — вручную.
Соглашения
Пути в сборке относительные (base: './' в Vite) — игра запускается в iframe портала.
Ассеты: спрайт-атласы, сжатые изображения, звук в ogg/mp3.
Баланс-числа только в data/, не в коде.
Каждая новая механика в core/ сопровождается тестом.
Команда и процесс
Пользователь — геймдизайнер. Общение с ним — на украинском. Промпты агентов, скиллов и код-комментарии — на английском.
Основная сессия — техлид: планирует, делегирует, собирает результат.
Дизайн-документы: docs/design/ (зона дизайнера, источник истины по задумке). Неясное в дизайне не выдумывать — помечать DESIGN-TBD и спрашивать.
Агенты (.claude/agents/):
core-engineer — src/core/ и тесты.
phaser-dev — src/render/, UI, ввод.
balance-analyst — src/data/, симуляции в tools/sim/.
platform-release — src/platform/, src/save/, сборка, CI, вес.
reviewer — read-only проверка правил перед коммитом.
ui-designer — визуальный стиль меню и HUD, UI-кит, шрифты, иконки (стиль-гайд: docs/design/ui-style.md).
Скиллы (.claude/skills/): /add-skill, /add-affix, /add-mob — добавление контента из описания дизайнера; /design-interview — интервью с дизайнером, ответы записываются в docs/design/.
