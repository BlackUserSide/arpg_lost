# Дизайн-документи

Зона геймдизайнера. Ці файли є джерелом істини щодо *задуму*. Агенти читають їх перед роботою й не вигадують дизайн самостійно. Якщо чогось бракує, вони позначають питання як `DESIGN-TBD` і повертають його дизайнеру.

## Структура

Один файл на систему. Створюйте за потреби за шаблоном `_template.md`.

| Файл | Система |
|---|---|
| `combat.md` | Хіт, крит, опори, статуси, смерть |
| `stats.md` | Стати, модифікатори, теги |
| `classes.md` | Класи та їхні скіли |
| `skill-modifiers.md` | Модифікатори скілів (камені підтримки) |
| `items.md` | Слоти, рідкість, афікси, тири |
| `crafting.md` | Валюта та операції крафту |
| `passives.md` | Дерево пасивок, ключові вузли |
| `progression.md` | Досвід, рівні, розблокування |
| `maps.md` | Карти, хвилі, боси, рівні карт, лут |
| `mobs.md` | Мобы, поведінка, боси |
| `hub-ui.md` | Хаб, інвентар, меню |
| `account.md` | Акаунт CrazyGames, персонажі, профіль, рекорди |
| `art.md` | Арт-напрям |
| `controls.md` | Керування на десктопі й мобільних |

## Правила

- Числа в документі є орієнтирами задуму. Остаточні значення живуть у `src/data/`, ними займається balance-analyst.
- Пропозиції агентів у документі позначаються `> PROPOSAL (agent):` і чекають рішення дизайнера.
- Статус документа вказується вгорі: `draft` / `approved` / `implemented`.
