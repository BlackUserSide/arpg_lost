# UI: стиль-гайд

**Статус:** draft
**Етап:** M3–M4

## Мета
Інтерфейс у дусі темного фентезі (Diablo / PoE), який читається на телефоні й не перевантажує.

## Рішення (з art.md)
- Темне фентезі: кам'яні / металеві рамки, піксельний або «середньовічний» шрифт.
- Світ — мультяшні 3D-рендери KayKit у темних підземеллях; UI має пасувати до них.
