# Крафт

**Статус:** draft
**Етап:** M3 (версія 0.3)

## Мета
Непотрібний лут перетворюється на прогрес: розбираєш зайве → покращуєш свій предмет. Крафт дає контроль над екіпіровкою, але найкращі предмети все одно треба вибити.

## Правила

### Валюта (інтерв'ю 2026-10-22)
- **Осколки** — основна валюта: з розбору предметів (`items.md`) і модифікаторів скілів (`skill-modifiers.md`), зі скринь, з ендгейм-шкали. Спільні для акаунта (`account.md`).
- **1–2 рідкісні валюти** для сильних операцій. Падають з еліт і боса.
- Рішення 2026-10-23: на старті **одна** рідкісна валюта — **«Есенція»** (падає з еліт і боса); друга — пізніше, якщо знадобиться.

### Операції
| Операція | Що робить | Ціна |
|---|---|---|
| Підвищення рідкості | звичайний → магічний → рідкісний; додає афікси до мінімуму нової рідкості | осколки |
| Додати афікс | новий випадковий афікс у вільний слот (префікс або суфікс) | осколки |
| Перекат афікса | **один обраний гравцем** афікс замінюється на інший випадковий | осколки + рідкісна |
| Перекат чисел | той самий афікс і тир, нове значення в межах тиру | осколки |
| Видалити афікс | прибрати обраний афікс, звільнити слот | осколки + рідкісна |

- Фіксації афіксів і перекату всіх афіксів разом немає: перекат одного + видалення дають повний контроль.
- **Ціна росте з кожною операцією на тому самому предметі.** Ідеальний предмет можливий, але дорогий; лут лишається цінним. Предмет не ламається.
- Крафт — **вкладка в інвентарі, лише в хабі**: обрав предмет → панель операцій.
- **Унікальні й легендарні предмети не крафтяться.** Їхня цінність — у випадінні.
- Усі операції — через seeded RNG; новий афікс і тир беруться з тих самих таблиць, що й при випадінні (`data/affixes`), з урахуванням рівня предмета.

## Крайні випадки
- Рішення 2026-10-23: лічильник крафту зберігається в предметі й не скидається; **перекат чисел не рахується** в лічильник (доводка не дорожчає).
- Рішення 2026-10-23: «Додати афікс» неможливий без вільного слота; «Видалити» **не може** опустити предмет нижче мінімуму його рідкості (магічний ≥1, рідкісний ≥3) — для цього спершу треба додати.
